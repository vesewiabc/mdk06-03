# АИС ресторана «Гурман»

Автоматизированная информационная система ресторана на Flask + SQLite,
разработанная по ТЗ (ГОСТ 34.602-89). Реализует подсистемы:

- **Управление заказами** — столы, приём заказов, отправка на кухню/бар, оплата
- **Складской учёт** — товары, остатки, приход/списание, инвентаризация, заявки на пополнение
- **Управление блюдами / производственный учёт** — меню, категории, технологические карты
- **Учёт персонала** — сотрудники, график смен, фонд оплаты труда
- **Финансовый учёт** — отчёты по выручке, топ блюд, низкие остатки склада

## Установка и запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# создать базу и наполнить демо-данными
flask --app app init-db
flask --app app seed-db

python run.py
```

Приложение будет доступно на http://127.0.0.1:5000

## Роли и права доступа

Разграничение доступа реализовано декораторами `login_required` /
`roles_required` в `utils.py`: каждый модуль проверяет роль текущего
пользователя (`g.user["role"]`) перед выполнением действия — в соответствии
с требованием ТЗ о разграничении прав в зависимости от ролей.
